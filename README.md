## 🚀 How to Run Locally

You do not need any web server or package manager to run this website.

1. Navigate to the portfolio folder:
   ```powershell
   c:\Users\BABA RISHIK\Desktop\portfolio
   ```
2. Double-click `index.html` to open it in Google Chrome, Microsoft Edge, Mozilla Firefox, or any modern web browser.

Alternatively, if you have Python installed, you can launch a local development server:
```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
